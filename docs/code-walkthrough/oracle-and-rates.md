# Oracle and interest module walkthrough
Frozen source: b97598b987dfee2a0bf2ee40c95d2ebda1ad62fe.

[FeedOracle](../../src/FeedOracle.sol): constructor validates contract addresses, heartbeat and feed decimals, fixes normalization scales and optionally binds a sequencer. price first checks the sequencer status/restart/grace, then reads both USD feeds. _read rejects nonpositive answers, invalid round ordering, missing/future timestamps and exceeded maxAge. It scales answers to WAD; price computes collateralUSD/loanUSD. State never changes after construction. Alternatives such as last-good-price or AMM spot fallback are deliberately absent because their trust/economic behavior needs separate justification. FeedOracleTest exercises freshness boundary, stale/future/zero timestamps, answer bounds, rounds, depeg ratio, mixed decimals and sequencing. A test-only external deployment factory removes coverage misattribution across inline constructor call sites; final raw oracle coverage is 8/8 branches.

[InterestRateModel](../../src/InterestRateModel.sol): rate is a pure bounded piecewise function. Up to utilization 0.8, slope contributes 0.08 APR; above it the remaining 0.2 utilization contributes 0.9 APR. The curve is continuous at 10%, ends at 100%, and has no administrator. Bounded monotonic fuzz and Python rational reference vectors check it. Runtime multiplication is bounded by utilization ≤WAD, so the simple integer products here fit uint256. Index growth uses Math.mulDiv in the vault.

The independent reference uses Python Fraction/integer arithmetic and a deterministic seed. DifferentialTest compares 256 fixtures plus actual checkpointed index storage. Formula agreement still assumes this chosen economic model is suitable; it does not prove the incentive system is optimal.
